# POKÉ ARENA v0.3 — 액션 배틀

기존 v0.2 프론트엔드를 이 프로젝트로 교체해 사용합니다. 기존 로그인 API와 방/팀 선택 WebSocket 서버를 그대로 사용하며 백엔드 수정은 필요하지 않습니다.

## 실행 및 배포

```sh
npm ci
npm run dev
npm test
npm run build
```

Netlify 빌드 명령: `npm run build`, 게시 디렉터리: `dist`. 기존 `VITE_ARENA_WS_URL` 환경변수와 `/api` 리다이렉트 설정을 유지하세요. `.env.example`의 주소는 예시입니다. `dist`는 현재 배틀 서버 `wss://arena.3-34-220-192.sslip.io/api/arena/ws`로 미리 빌드했습니다. 서버 주소가 바뀌면 실제 환경변수로 다시 빌드하세요.

## 플레이

로그인 → 연습방 만들기 → 포켓몬 3마리 선택 → 팀 확정 → 전투 시작.

- WASD: 이동 (대각선 속도 정규화)
- 마우스: 조준 / 왼쪽 클릭 또는 누르고 있기: 기본공격
- Q, E: 포켓몬별 기술 (마우스 방향 또는 위치)
- 스페이스: 이동 방향으로 짧은 회피. 정지 중에는 조준 방향. 약 125px 이동, 0.23초 피격 무적, 1.65초 재사용 대기. 잔상 표시.
- ESC: 일시정지 / 계속. 창 전환 시 자동 일시정지.

각 팀 한 마리씩 전투하며 기절 시 다음 파트너가 자동 출전합니다. 3마리를 먼저 쓰러뜨리면 승리합니다. 제한시간 3분 경과 시 팀 전체의 남은 HP 비율 합으로 승패를 정합니다. 결과 화면에서 재대결 및 팀 재선택이 가능합니다.

현재 전투는 브라우저에서 실행하는 1인 봇 트레이닝입니다. 서버는 기존 계정·방·팀 선택을 담당합니다. 전투 결과나 보상은 서버에 저장되지 않으며 새로고침하면 전투는 초기화됩니다.

## Q / E

| 포켓몬 | Q | E |
|---|---|---|
| 피카츄 | 10만볼트 | 번개 |
| 리자몽 | 화염방사 | 불대문자 |
| 거북왕 | 하이드로펌프 | 소용돌이 |
| 이상해꽃 | 솔라빔 | 오물폭탄 |
| 팬텀 | 섀도볼 | 오물폭탄 |
| 괴력몬 | 크로스촙 | 폭발펀치 |
| 잠만보 | 누르기 | 잠자기 |
| 루카리오 | 파동탄 | 신속 |
| 한카리아스 | 드래곤다이브 | 지진 |
| 가디안 | 사이코키네시스 | 문포스 |

붉은 범위는 상대의 기술 예고입니다. 번개·불대문자·솔라빔 등은 짧은 예고 뒤 판정됩니다. 소용돌이·오물폭탄 등은 일시적으로 이동을 늦춥니다. 잠자기는 시전 후 회복하며, 피격 시 취소됩니다. 공격 돌진과 회피의 무적은 별개로, Q/E 돌진에는 무적이 없습니다. 기술 수치·피해는 이 액션 게임용으로 조정했습니다.

트레이너 스프라이트 및 포켓몬 애니메이션 출처는 `public/arena/credits.html`을 참고하세요. `public/arena/ui/battle-fx.png`는 내장 이미지 생성 도구로 제작한 4×4 투명 VFX 아틀라스입니다. 프롬프트: 전기·불꽃·물·잎·섀도볼·주먹·지진·파동탄·드래곤클로·문포스·신속·피격·번개·폭발·소용돌이·사이코키네시스의 픽셀 이펙트 16종을 투명한 4×4 그리드로 제작. 원본 포켓몬 스프라이트와 함께 Canvas에서 합성합니다.
