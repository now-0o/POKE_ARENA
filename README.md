# POKÉ ARENA v0.6 — 안정 카메라 · 입체 픽셀 연출 · 포켓몬 교체

기존 프론트엔드를 이 폴더로 교체합니다. 기존 로그인·방·팀 선택 서버를 사용하며 백엔드 수정은 필요하지 않습니다.

## 실행 / 배포

```sh
npm ci
npm run dev
npm test
npm run build
```

Netlify: 빌드 `npm run build`, 게시 폴더 `dist`. 기존 `VITE_ARENA_WS_URL` 환경변수와 `/api` 프록시를 유지하세요. 포함된 `dist`는 `wss://arena.3-34-220-192.sslip.io/api/arena/ws`로 빌드했습니다.

## v0.6 변경

### 안정 카메라

최대 줌을 1.85배에서 1.22배로 줄였습니다. 줌인 속도는 초당 최대 .07배, 줌아웃은 최대 .22배로 제한합니다. 중심점의 가로 65·세로 40 월드 픽셀 안에서는 추적하지 않고, 이동 속도는 초당 32로 제한합니다. 양 포켓몬이 화면 끝에 몰리면 우선 줌을 풀어 잘리지 않게 합니다. 전투 우측 아래에서 '안정 / 고정' 전환이 가능하며 선택을 저장합니다. 동작 줄이기 설정에서도 고정합니다.

### 포켓몬 교체

- 1 / 2 / 3키 또는 왼쪽 위 팀 버튼으로 교체합니다.
- 팀 공통 14초 재사용 대기입니다. 현재 포켓몬·기절한 포켓몬으로 교체할 수 없습니다.
- 교체 직후 .9초간 행동과 이동이 제한되며, 이때 받는 피해는 후딜 공략과 동일하게 20% 증가합니다. 무적은 없습니다.
- 들어오는 포켓몬의 Q/R은 최소 2초, 회피는 최소 1.2초 동안 사용할 수 없습니다. 즉시 기술만 쓰고 도망가는 교체를 막습니다.
- 공격 준비·사용 중, 회피 중, 경직·속박 중에는 자발적으로 교체할 수 없습니다.
- 체력·팀 궁극기 게이지는 유지됩니다. 대기 포켓몬의 쿨타임과 상태 지속시간은 흐릅니다. 교체한다고 체력이 회복되지 않습니다.
- 기절 후 자동 교체는 공통 대기시간과 무관하게 작동합니다.
- 봇도 같은 함수와 동일한 페널티를 사용합니다. 현재 포켓몬 체력이 38% 미만이거나 일정 전투 간격에 거리가 확보되면 살아 있는 예비 포켓몬 중 체력 비율이 높은 쪽으로 교체합니다. 기절할 때만 바뀌던 동작을 개선했습니다.

### 참고 이미지 스타일 적용

현재 기술 기반은 2D Canvas입니다. 실제 3D 엔진으로 교체하지는 않았고, 새 석재 경기장, 두께와 명암을 가진 96프레임 스프라이트, 바닥 접촉광, 접지 그림자, y좌표에 따른 포켓몬/투사체 앞뒤 순서로 2.5D 깊이를 강화했습니다. 원본 포켓몬 애니메이션은 PMDCollab 시트를 유지합니다.

참고 이미지는 스타일 분석용으로만 사용했으며 ZIP에 포함하지 않았습니다. 새 PNG 4장은 매 프레임 형태를 바꿔 다시 생성했습니다. 6×4 그리드와 6프레임 재생 구조를 유지합니다. 원본 생성 이미지의 넓은 반투명 광채는 알파 머티리얼에서 억제하고, 바닥에 닿는 국소 광원은 별도 레이어로 표현합니다. 배경의 원근 형태에 맞춰 경기장 좌우 이동 한계도 y좌표에 따라 달라집니다.

## v0.5에서 유지한 기능

- 두 포켓몬 사이 거리와 중간 지점을 추적하는 부드러운 줌 카메라. 가까워지면 최대 1.22배, 멀어지면 1배까지 복귀합니다. 줌 아웃이 더 빠르게 반응하며 마우스 좌표는 현재 카메라의 역변환을 사용합니다. OS 동작 줄이기 설정에서는 카메라 움직임을 끕니다.
- 전투 VFX를 실제 PNG 스프라이트 시트 4장, 16종×6프레임=96장으로 교체했습니다. 프레임마다 모양이 다릅니다. `combat-fx.js`가 소스 사각형을 바꾸어 12~14fps로 재생합니다. 단일 이미지의 확대·회전만으로 애니메이션을 흉내 내지 않습니다.
- 원본 이미지의 반투명 광채는 게임의 스프라이트 머티리얼에서 그리지 않고 불투명한 픽셀만 사용합니다.
- 일반 기술은 Q/R, 궁극기는 E로 변경했습니다. 이전 E 기술은 R에서 그대로 사용합니다.
- 이상해꽃 잎날가르기는 돌아오며 왕복 명중할 수 있습니다. 리자몽 화염방사는 화상을 남깁니다. 팬텀 섀도볼은 저주를 쌓습니다. 루카리오 파동탄은 표식을 남기고 신속으로 터뜨리면 추가 피해를 줍니다.

## E 궁극기

궁극기 게이지는 팀 공용이며 교체 후에도 남습니다. 공격 명중 피해의 50%, 받은 피해의 22%, 정밀 회피 성공 10, 전투 중 초당 2.4를 얻습니다. 최대 100이고, 준비 완료 후 E를 누르면 전량 소비합니다. 준비·경직·후딜 중 사용 제한은 일반 기술과 같습니다.

시전 시 0.55초 동안 포켓몬·기술명이 나오는 컷인과 전투 정지가 들어갑니다. 이후 공격 예고와 실제 판정이 이어지며 범위를 벗어나거나 회피할 수 있습니다. 큰 궁극기 명중에는 약 0.045초의 짧은 타격 정지가 있습니다. 봇도 같은 게이지 규칙을 사용합니다.

## 화면

- 로그인·방·선택 화면은 창 높이에 맞춰 자동 축소되어 페이지 스크롤이 생기지 않습니다.
- 전투는 브라우저 창 전체를 사용합니다. 웹사이트 헤더·푸터를 숨기고 HP·타이머·쿨타임을 경기장 위에 표시합니다.
- 경기장은 1600×900 월드, 실제 이동 범위 1360×565입니다. 이전보다 이동 면적이 약 2.3배 넓습니다.
- 스프라이트 배율은 2에서 1.5로 줄였습니다. 창 비율이 달라도 캐릭터와 판정은 같은 비율로 표시됩니다.
- 기술 UI는 하단 중앙에 큰 재사용 대기 숫자, READY 표시, 진행 막대와 키를 표시합니다. 기술에 마우스를 올리면 기능을 볼 수 있습니다.

## 조작

WASD 이동 · 마우스 조준 · 왼쪽 클릭 1회당 기본공격 1회 · Q/R 일반 기술 · E 궁극기 · SPACE 회피 · 1/2/3 교체 · ESC 일시정지. 창 전환 시 자동 일시정지합니다.

이제 기본공격은 누르고 있어도 연사되지 않습니다. 공격 방향은 준비 동작 시작 시 고정됩니다. 기본공격은 회피로 취소할 수 있지만 기술을 준비·사용하는 중에는 다른 기술과 회피를 겹칠 수 없습니다. 기술마다 준비 시간, 사거리, 유지 시간과 후딜이 다릅니다. 회피 재사용 대기는 2.3초, 피격 무적은 0.23초입니다.

상대의 예고를 보고 사거리를 벗어나거나 옆으로 피한 다음 후딜에 반격하세요. 후딜 중 피격은 피해가 20% 증가합니다. 회피 무적으로 공격 판정을 넘기면 '회피 성공'이 뜨고 1.25초 안에 가하는 다음 명중 피해가 20% 증가합니다. 단순히 범위 밖으로 이동한 회피에는 강화가 붙지 않습니다. 경직에는 재경직 방지 시간이 있습니다.

봇은 공격 후 잠시 거리를 다시 잡습니다. 투사체나 위치 예고를 확인한 뒤 반응하며, 숨겨진 입력을 미리 읽지 않습니다.

## 전투 진행

로그인 → 연습방 → 3마리 선택 → 팀 확정 → 전투 시작. 기절하면 다음 파트너가 자동 출전합니다. 3분 제한이며 시간 경과 시 남은 팀 HP 비율 합으로 판정합니다. 결과에서 재대결·팀 재선택이 가능합니다.

1인 봇 트레이닝이며 전투는 브라우저에서 실행됩니다. 계정·방·팀만 기존 서버를 사용하고 전투 결과·보상은 서버에 저장하지 않습니다. 새로고침하면 전투가 초기화됩니다.

## 에셋

`public/arena/fx/elements.png`, `force.png`, `slashes.png`, `field.png`: 내장 이미지 생성 도구로 이 게임용으로 제작한 PNG 시트. 각각 6열×4행이고, 한 행이 6프레임 애니메이션입니다. 프롬프트 요약: PMD/NDS풍 투명 픽셀 이펙트, 각 프레임을 별도로 그려 준비·전개·타격·분산의 모양이 달라지도록 제작. 전기·불꽃·물·잎 / 섀도볼·격투·대지·파동 / 드래곤클로·문포스·신속·피격 / 번개·불대문자·소용돌이·사이코 계열로 구성했습니다. 실제 게임에서는 알파 컷오프로 광채를 제외하고 사용합니다.

`public/arena/ui/league-stadium.png`는 참고 이미지의 명암·질감을 바탕으로 내장 이미지 생성 도구로 새로 만든 석재 경기장입니다. 새 스프라이트 시트의 프롬프트: 현대적인 포켓몬 픽셀 아레나, 명암 면으로 표현한 입체적인 화염·물줄기·대지·파동 등, 절제된 국소광, 프레임별 준비·전개·타격·소멸, 투명한 6×4 그리드. 원본 참고 이미지의 문구·로고·구도는 복제하지 않도록 지시했습니다. 포켓몬 Idle·Walk·Attack은 기존 PMDCollab 애니메이션이고 트레이너는 Pokémon Showdown의 레드 스프라이트입니다. 출처·제작자 기록은 `public/arena/credits.html`을 참고하세요.

## 검증

`npm test`의 24개 항목은 교체 페널티·HP 유지·봇 자발적 교체·안정/고정 카메라와 일반 기술, 카메라 좌표와 줌 완화, 게이지 획득·소비, 10종 궁극기, 연계, 재대결 초기화 등을 검증합니다. 별도의 로컬 브라우저 검증에서 로그인~전투~팀 수정 화면 전환, 여러 창 크기의 스크롤·HUD, 실제 E키 게이지 소비·컷인, 16종 모두 6개 서로 다른 프레임 재생을 확인했습니다. 브라우저의 계정·방 응답은 테스트용 모의 응답을 사용했습니다.
